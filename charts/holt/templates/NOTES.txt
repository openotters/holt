🌀 holt is deploying.

1. Find the tunnel address peers will dial (service {{ include "holt.fullname" . }}-tunnel):

   kubectl -n {{ .Release.Namespace }} get svc {{ include "holt.fullname" . }}-tunnel

2. Enroll your first peer (mints a join token bound to that address):

   kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "holt.fullname" . }} -- \
     holt enroll web --state /data --hub-addr <tunnel-address>:{{ .Values.service.tunnel.port }}

3. On the peer machine, expose a local service through the hub:

   holt expose localhost:3000 --token <paste>

4. Reach it through the proxy port (private by default):

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "holt.fullname" . }} {{ .Values.service.proxy.port }}
   curl -H 'x-tunnel-peer: web' http://127.0.0.1:{{ .Values.service.proxy.port }}/

{{- if .Values.hub.ui }}

5. The web console (list, kill, block, enroll):

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "holt.fullname" . }} {{ .Values.service.admin.port }}
   open http://127.0.0.1:{{ .Values.service.admin.port }}/
{{- end }}

{{- if .Values.ingress.tunnel.enabled }}

The tunnel is exposed through an ingress: peers dial
{{ include "holt.advertiseAddr" . }} (stamped into join tokens automatically;
hub.advertiseAddr overrides it). The tunnel is a WebSocket: any edge
forwarding plain HTTP/1.1 upgrades carries it, Cloudflare public
hostnames included. Do NOT enable an HTTP/2-to-origin setting on this
hostname (e.g. the cloudflare-tunnel http2-origin annotation); it
breaks the upgrade.
{{- end }}

The hub state (JWT secret, blocklist) lives in the
{{ ternary (printf "PVC %s" (.Values.persistence.existingClaim | default (include "holt.fullname" .))) "pod (persistence is DISABLED: every restart invalidates all join tokens)" .Values.persistence.enabled }}.
{{- if or .Values.ingress.admin.enabled .Values.ingress.proxy.enabled }}

⚠️  SECURITY: you enabled an ingress. The admin API mints join tokens
    and can kill/block peers; the proxy reaches every peer's service.
    Neither has built-in auth. Make sure an authenticating layer (a
    zero trust proxy such as Cloudflare Access, or an auth ingress)
    sits in front of it. The DNS-rebinding host guard is on; "*" in
    hub.allowedHosts disables it.
{{- end }}
